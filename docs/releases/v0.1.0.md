## nocdeck 0.1.0 — the first release

A monitoring dashboard for anything with an IP address: full SNMP depth, history,
thresholds and alerts, as a web page **and** a desktop window over one engine.

### What is in it

- **SNMP v1/v2c**, hand-written codec, no dependencies — CPU, memory, temperature, fans,
  voltage, power, disk, battery runtime, optical dBm, every port's state, speed, traffic,
  utilisation and error counters, the whole entity-sensor table, PoE power per port.
- **Reachability for the rest** — ICMP with a TCP fallback that needs no root, TCP port
  checks, and an HTTP(S) check that also watches the certificate expiry date.
- **History** in one SQLite file: raw samples, hourly rollups, an append-only event
  table, per-device 24-hour availability.
- **Thresholds with a direction** — high-is-bad for CPU and temperature, low-is-bad for
  battery, runtime and optical power — plus hysteresis so one lost packet is not an
  outage, and flapping detection so a bad cable is not forty alerts.
- **Alerts** to Telegram, email (SMTP) and webhooks: one message per problem rather than
  per poll, storms collapsed into a digest, quiet hours that criticals ignore.
- **The web dashboard** with a fleet view, per-device pages, an events page, a
  JSON API and a dark wall view for a screen in the NOC.
- **The desktop window** (`pip install "nocdeck[desktop]"`): the same fleet, device,
  events, alerts and settings tabs, polls on a background thread, full-screen wall, and
  `--shot` to render a frame to a PNG on a machine with no display.
- **`nocdeck demo`** — eleven imaginary devices (switches, a firewall, a router, servers,
  a printer, a UPS) answered by a fake SNMP agent that implements the same OIDs real gear
  does, polled through the real collector, thresholds, store, alerts and both dashboards.
  The demo scripts an outage, a dropped port and a temperature climbing toward its
  warning line, so the alert path can be seen working before the tool is pointed at
  production.

### Install

```bash
pip install nocdeck
pip install "nocdeck[desktop]"
```

### Verified

181 tests, no network required, on Python 3.9 – 3.13. The SNMP codec is pinned byte for
byte; the collector runs against a fake agent; the desktop window is driven offscreen in
the suite, and the release build smoke-tests both frozen Windows executables before the
release is created.
